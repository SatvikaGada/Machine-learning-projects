# Anomaly Detection in Stock Prices | Z-Score, Isolation Forest & Residuals

# Project Information

In this project, I explore anomaly detection in stock prices using techniques like Z-Score, Isolation Forest, and Residual Analysis. Also demonstrated how to identify unusual price movements, detect market anomalies, and improve financial data analysis. By leveraging these statistical and machine learning methods, gained insights into detecting outliers that could indicate potential trading opportunities or risks.
